# سوا Sawa v2
تطبيق مشاهدة جماعية بسيط: غرف + رابط دعوة + مزامنة فيديو + شات لحظي.

## التشغيل
1. ثبّت Node.js 18+
2. شغّل: `npm install`
3. ثم: `npm start`
4. افتح http://localhost:3000

## النشر
يمكن نشره على أي استضافة Node.js تدعم WebSockets. أمر التشغيل: `npm start`.

ملاحظة: التطبيق لا يتجاوز DRM ولا يعيد بث Netflix/Shahid. استخدم روابط فيديو مباشرة تملك حق تشغيلها.
